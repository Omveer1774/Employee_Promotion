⚡ Employee Promotion Intelligence Dashboard

An interactive web-based dashboard built using Python and Streamlit to demonstrate an employee promotion prediction system using Artificial Neural Networks (ANN).

📌 Project Overview

The Employee Promotion Intelligence Dashboard provides an interface to enter employee details, review performance metrics, and visualize a simulated promotion probability.

The project demonstrates the potential use of Artificial Intelligence and Machine Learning in employee analytics.

Important: This version uses a randomly generated demo score. A trained ANN model has not yet been integrated, so the results are not real predictions.

✨ Features

- Interactive employee information form
- Education and demographic details
- Department selection
- Training score and previous year rating
- Years of service and KPI information
- Awards and training metrics
- Promotion probability visualization
- Interactive progress bar
- Modern dashboard with custom CSS styling
- Wide-screen layout and sidebar controls

⚙️ Installation

Step 1: Clone the repository

git clone https://github.com/YOUR-USERNAME/Employee-Promotion-AI.git

Replace "YOUR-USERNAME" with your GitHub username.

Step 2: Open the project directory

cd Employee-Promotion-AI

Step 3: Install dependencies

pip install -r requirements.txt

Step 4: Run the application

streamlit run app.py

The application will open in your default web browser.

📊 How It Works

1. Enter employee details using the sidebar.
2. Select education level and department.
3. Provide training score and previous year rating.
4. Enter length of service and achievement details.
5. Click the Run Evaluation button.
6. View the simulated promotion probability and progress bar.
