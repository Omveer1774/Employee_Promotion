# 🚀 Employee Promotion Prediction App

An interactive Machine Learning web application built with Streamlit to evaluate and predict employee promotion eligibility based on performance metrics, training scores, and organizational attributes.

---

## 📌 Features

* **Interactive Form:** Simple UI for entering employee details (e.g., department, performance rating, KPI score, length of service).
* **Instant Predictions:** Real-time evaluation powered by a trained Machine Learning model.
* **HR Support:** Helps streamline performance reviews and objective decision-making.

---

## 🛠️ Tech Stack & Tools

* **Python 3.12**
* **Streamlit** (Web Interface)
* **Scikit-Learn / Pandas / NumPy** (Data Processing & Model Inference)
